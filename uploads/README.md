# Uploads

Put original files for one module in one folder, for example `uploads/MOD1004AA/note.md`.

Only that folder (and that module’s assignment under `Essay-writer/<module>/`) is read for that essay. Paths outside it are refused.

A file here is not a citation until research includes it. Text and Word files can be checked. Missing author, year, or title details are not invented from thin air.

These files stay on this computer in this folder.
