# Essay folders

One folder per module, for example `Essay-writer/MOD1004AA/`.

Create the folder when you start that assignment. Put the assignment file here as `brief.md`, `brief.txt`, or `brief.docx`.

Files you upload for the same module go in `uploads/MOD1004AA/`, not in this folder and not under another module.

Working files for the essay (saved stages and the Word draft) also live under this module. They are not your sources.

Do not copy another module’s assignment or uploads into this folder. Do not put your name or student number in the folder name.
