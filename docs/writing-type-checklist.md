# Writing-type checklist

A new writing type does not ride the essay or report contract. The brief is read once onto the assignment record. Stage 2, stage 3, stage 5, and Word read that record.

## Required mapping

Register a brief-to-record mapping before the type can be saved. The mapping fills:

- named parts, in brief order, or a count with the note that the brief did not name them
- title-page fields, including whether a registration number or a name is required
- the findings-opening label: `how_to_score_high`, `mark_scheme`, or `none`
- the lock the save enforces

A type with no mapping fails closed. The stage prompt says so. The save and Word do not fall through to an essay thesis or a report purpose and scope.

Essay stays a thesis. Report stays purpose and scope. Neither stores a diary part list.

## Named parts

The list reader accepts a colon sentence, a heading plus dash or star bullets, and a heading plus `1.` or `1)` items. A short tail on the heading is part of the heading (`Workshop topics`). It stops at a blank line or the next heading. It does not hardcode a type name, a module code, or a real title. `Entry 1` is refused when the brief named the parts.

## Findings opening

The label lives on the assignment record. Diary with a mark table uses `how_to_score_high`. Essay and report with a scheme use `mark_scheme`. The check that a findings note matches that label, and the mid-status sentence, are a later batch. This batch only stores the label.

## Title page

The fields are the ones the brief lists. Word refuses while a required registration number or name is empty, and the refusal names the field. The number printed is the one the student supplied, stored once on the sequence and reused on every Word write. It is not invented and it is not copied from a sample. A name is printed only when the brief asks. Essay and report still refuse a student number unless that brief asks. Stages 6, 7, 9, and the stage 10 final use one cover and one footer through write_docx. The page number sits where the assignment record says, including the lower right when the brief says so.
