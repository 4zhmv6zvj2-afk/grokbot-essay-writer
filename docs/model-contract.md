# Model contract

This page is the inventory of payloads the model supplies and the doors then
read. It records the check that exists on this tree. It does not change a
prompt.

`src/essay_writer/model_contract.py` parses the high-risk rows into a
dataclass before the door uses the value. Those rows are the confirmed
question, `smallerQuestions`, the stage-5 draft and the strip report, the
stage-6 review verdict and its `draft_text` tie, the findings note, and the
Word title. A bad shape is a `ContractRefusal` with the student sentence in
the refusal column, covered by `tests/test_model_contract.py`. The other rows
are safe unvalidated: the door already drops the bad value, or the sentence
is written by code. Hard checks refuse. Prose quality stays in the prompt.

The refusal column quotes the string the door returns. A blank cell means the
bad value is dropped or ignored and no refusal is spoken for that payload.
