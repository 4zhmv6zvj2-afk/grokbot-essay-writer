## 2. Establish a thesis

Lock the argument in one or two sentences that answer the question. This file has no purpose-and-scope alternative.

**Guideline:** Academic skills, How to write a university essay — thesis and argument.

- Record an initial response, possible answers, opinions, and what you already know, including related topics or frameworks, before the thesis is locked.
- Question the terms. Is there an agreed approach? If not, how the approaches differ, which one you will use, and how the key concepts relate.
- Broaden first (brainstorm, keep the ideas), then narrow. The locked thesis is the narrowed claim.
- The thesis answers the question in one or two sentences you can discuss throughout.
- The essay is balanced. Opposing views are examined only when a gathered source states them.
- Approve the save before this thesis is treated as locked.

## 3. Write an essay plan

Outline the introduction, the body, and the conclusion. The points are the reasons for the thesis. Scale the number of points to the length. For about 1,000 to 1,500 words, aim for 3 to 4 main points.

**Guideline:** Academic skills, How to write a university essay — essay plan.

- The plan holds the thesis and the main points as the reasons for that answer, in logical order.
- Each main point has room for reasoning and gathered evidence, and names sources you expect to use.
- Revise the plan after research. If the plan is itself assessed, follow that assessment’s form.
- Approve the save before the plan is locked.

## After research, revisit the plan

After the annotated bibliography and the critical review are saved, revisit the stage 3 plan before the first draft. Revisit the thesis only if the research breaks it. The thesis should still be the best one-sentence answer. A thin edit is allowed. A break is not a thin edit.

Check that the section arguments still hold, that the word weights still match the brief, and that each source type is a real title, with gaps named. Leave out anything the research never showed. Do not invent sources. Use only the year printed in the opened source. Do not add a second year.

If anything changes, show what changed and why, from the gathered sources, and record that in the tracking note. Approve that save again before the first draft. If the thesis breaks, approve stage 2 again and then approve stage 3 again. Do not silently rewrite the plan into the draft.

## 5. Write your first draft

Write the essay as an argument that answers the question. The critical-review notes are evidence for that argument. Do not paste those notes in as the draft. The opening follows this argument: a thesis that answers the question, then a road map of the main ideas. Do not open with a general sentence built only from the topic nouns. Each body paragraph is one idea. A paragraph closer must not only restate the topic sentence. Make it assignment-specific: a cited finding, a limit, or a figure. The close stays with this argument and adds no new information. Do not close with an automatic In conclusion that only restates the topic. Walk **Essay shape** below.

A section the brief names as reflection uses the reflective-writing rules in `docs/academic-writing-helpers.md`. The rest of this file stays an essay.

Paraphrase, summary, and quotation follow the source-use note in `docs/academic-writing-helpers.md`. Opposing views come only from gathered material. Do not invent sources. Approve the draft before treating it as locked for Word.

The first-draft chat stays quiet until the finished draft is saved. When the critical-review notes are too long, follow the stage 5 checklist in `docs/academic-writing-helpers.md`: drop only a repeated model line, then groups that fit, then a re-opened passage. Do not cut a note short in silence, and do not invent a quotation.

## Essay shape

From How to write a university essay. Stage 5 walks this. Drafting is not a straight line: go back to reading when a draft shows a gap.

**Introduction** follows this argument:

- A thesis that answers the question.
- A road map that names the main ideas.
- No opening sentence built only from the topic nouns.

**Body.** Develop the discussion that answers the question. Show that you have grasped the reading. Use exposition, evidence, and examples. If the question has more than one part, give each part its own stretch of the body.

**Each body paragraph** is one idea:

- A topic sentence that states the idea.
- Supporting sentences that explain it.
- Evidence from the research, or an example.
- Analysis of why that evidence matters.
- A closing sentence that is assignment-specific: a cited finding, a limit, or a figure. It must not only restate the topic sentence.

**Conclusion** stays with this argument:

- No automatic “In conclusion” that only restates the topic.
- End on an assignment-specific cited finding, a limit, or a figure.
- No new information.

A transition into the next stage of the argument names the next claim. It does not only restate the paragraph just finished.
